# Generators — builders and test scaffolds from OpenAPI

`ApiTestFramework.OpenApi` turns an OpenAPI 3 document into C# source; `ApiTestFramework.Generator.Cli`
runs it for one consumer project, as described by a `generator.json`. Nothing in either project
knows a concrete service.

| Generated | From | Compiled? | Edited by hand? |
|-----------|------|-----------|-----------------|
| Fluent test-data **builders** `*Builder.g.cs` | request-body schemas (transitively) | yes | **never** — customize in a partial class |
| **Test scaffolds** `<Service>GeneratedTests.cs.txt` | every operation × every documented response code | no (`.txt`) | copy what you need into a real `.cs` fixture |

DTOs are **not** generated by this tool — use NSwag (configs in the example's `DemoShop.Clients`)
or write POCOs by hand. Builders reference the DTO types by schema name.

## Running it

```bash
dotnet run --project framework/src/ApiTestFramework.Generator.Cli -- --config path/to/generator.json
```

Without `--config` the tool looks for `generator.json` in the current directory. The demo shop wraps
this (plus optional swagger refresh and NSwag) in
[`examples/demo-shop/api-tests/scripts/regenerate-all.ps1`](../../examples/demo-shop/api-tests/scripts/regenerate-all.ps1).

## `generator.json` reference

Paths are relative to the config file. `{service}` is replaced with each service's `name`.
`//` comments are allowed.

```jsonc
{
  "swaggerDir": "MyProduct.Clients/swagger",           // where the swagger files live
  "regenerateHint": "scripts/regenerate-all.ps1",      // printed in builder headers
  "services": [
    { "name": "OrderService", "swagger": "order-swagger.json" }
  ],
  "builders": {                                        // omit to skip builders
    "outputDir": "MyProduct.Steps/Builders/{service}/Generated",
    "namespace": "MyProduct.Steps.Builders.{service}",
    "dtoNamespace": "MyProduct.Clients.{service}"      // namespace of the DTO classes
  },
  "scaffolds": {                                       // omit to skip scaffolds
    "outputDir": "MyProduct.Tests/Generated",
    "namespace": "MyProduct.Tests.{service}",
    "fileExtension": ".cs.txt"                         // default; ".cs" compiles them directly
  }
}
```

Each run **deletes stale `*.g.cs`** in every builder output folder first, so a removed schema
disappears. Builder output is deterministic (no timestamps), which is what lets CI fail on stale
generated code. Scaffolds carry a `// Generated:` timestamp line.

## Builders

For every object schema reachable from a request body — through nested objects, arrays and
`oneOf` nullable wrappers — one `partial` builder class is generated:

```csharp
var request = new CreateOrderRequestBuilder()
    .WithCustomer(c => c.WithEmail("jane@example.com"))     // nested DTO via its own builder
    .AddItem(i => i.WithProductId(42).WithQuantity(2))      // element of a collection
    .WithShipping(s => s.WithMethod(ShippingMethod.Express))
    .With(r => r.Shipping!.Notes = null)                    // escape hatch for anything else
    .Build();
```

| Generated member | Behaviour |
|------------------|-----------|
| constructor | applies defaults, then calls `OnDefaultsApplied()` |
| defaults | Bogus values chosen by property name/format (`email`, `username`, `*name`, `description`, `street`, `city`, `postal`/`zip`, `country`, `category`, `note`, `phone`, dates, numbers…); enums → random value; nested objects → their builder's defaults. **Ids and collections get no default** — a builder never invents a foreign key |
| `With<Prop>(value)` | set a property |
| `With<Prop>(Action<NestedBuilder>)` | configure a nested DTO through its builder |
| `Add<Item>(value)`, `Add<Item>(Action<ItemBuilder>)`, `Clear<Prop>()`, `With<Prop>(List<>)` | collections |
| `With(Action<T>)` | arbitrary mutation (e.g. explicit nulls for negative tests) |
| `Build()` | calls `OnBeforeBuild(instance)`, returns the DTO |

### Customizing without touching generated code

Domain knowledge the spec cannot express goes into a hand-written half of the same partial class,
in a separate folder that the generator never touches:

```csharp
// MyProduct.Steps/Builders/Custom/CreateOrderRequestBuilder.cs
public partial class CreateOrderRequestBuilder
{
    partial void OnDefaultsApplied()                  // richer defaults
        => _instance.Shipping = new ShippingRequestBuilder().Build();

    partial void OnBeforeBuild(CreateOrderRequest r)  // invariants enforced on every Build()
    { if (r.Items.Count == 0) throw new InvalidOperationException("An order needs at least one item."); }

    public CreateOrderRequestBuilder ForProduct(int productId, int quantity = 1)   // domain verbs
        => AddItem(i => i.WithProductId(productId).WithQuantity(quantity));
}
```

## Test scaffolds

`TestCaseScaffolder` emits one test per **documented** response code of every operation, with a
name, category and Arrange/Assert hints derived from the HTTP method and the code. Each body is
`Assert.Inconclusive("Scaffold only — implement test body.")` until you write it.

| Code | Name suffix | Category |
|------|-------------|----------|
| 2xx | `ReturnsOk` / `ReturnsCreated` / `ReturnsAccepted` / `ReturnsNoContent` | Success |
| 400 | `WithInvalidPayload_ReturnsBadRequest` | Negative |
| 401 (secured operations) | `WithoutToken_ReturnsUnauthorized` | Security |
| 403 | `WithInsufficientPermissions_ReturnsForbidden` | Security |
| 404 | `WithUnknownResource_ReturnsNotFound` (path params) / `ReturnsNotFound` | Negative |
| 405, 409, 415, 422 | `WithUnsupportedMethod…`, `WithConflictingState…`, `WithUnsupportedMediaType…`, `WithSemanticallyInvalidRequest…` | Negative |
| 429, 500, 503 | `WhenRateLimitExceeded…`, `WhenServerFails…`, `WhenServiceUnavailable…` | Resilience |

Only documented codes are scaffolded — the quality of the scaffold is the quality of your contract.
Promoting a scaffold to a real test is [tutorial chapter 5](../tutorial/05-scaffold-and-promote-tests.md).

## Using the library directly

```csharp
var doc = OpenApiSpecLoader.LoadFromFile("swagger/inventory-swagger.json");

IReadOnlyList<EndpointDefinition> endpoints = OpenApiSpecLoader.GetEndpoints(doc);   // path, method, operationId, params, responses, auth
IReadOnlyList<SchemaDefinition> schemas = SchemaExtractor.GetRequestSchemas(doc);    // request DTO graph incl. enums

var builders = BuilderScaffolder.GenerateBuilders(schemas, "MyProduct.Clients.Inventory",
    "MyProduct.Steps.Builders.Inventory", sourceName: "inventory-swagger.json");     // file name → content
var cases = TestCaseScaffolder.GenerateTestCases(endpoints, "Inventory");
var code = TestCaseScaffolder.GenerateCSharpTestClass(cases, "MyProduct.Tests.Inventory");
```
